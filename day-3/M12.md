# M12 — Pull Request Workflow, Traceability & Human Merge Control

## Learning Goal

Bir engineering change'i reviewer'ın anlayabileceği traceable evidence'e dönüştürmek ve merge kararını insanda tutmak.

## Key Idea

```text
Requirement
→ Change
→ Tests
→ Diff
→ PR Evidence
→ Human Review
→ Human Merge
```

---

## D03-M12-P01 — Build a PR Evidence Package

### Mode

```text
Manual Mode
```

### Prompt

```text
Mevcut local change için bir Pull Request evidence package hazırla.

Henüz GitHub'da PR oluşturma.
Remote action yapma.

Şunları üret:

- Problem / Requirement
- Scope
- Architecture impact
- Files changed
- Behavior changed
- Tests run
- Test results
- Risks / trade-offs
- Explicit non-changes
- Reviewer questions
- Rollback / recovery note if relevant

Her claim'i mümkün olduğunca local evidence'e bağla.

Bilmediğin şeyi uydurma.
```

### What to Observe

PR description implementation narrative değil, reviewer evidence'i üretiyor mu?

---

## D03-M12-P02 — Traceability Check

### Prompt

```text
Hazırlanan PR evidence package'i traceability açısından değerlendir.

Şu mapping'i oluştur:

Requirement
→ Acceptance Criterion
→ Code Change
→ Test Evidence

Eksik mapping varsa flag et.

Henüz file değiştirme veya remote action yapma.
```

### Discussion Point

> **Traceability, “çok açıklama yazmak” değil; requirement ile evidence arasında zincir kurmaktır.**

---

## D03-M12-P03 — Human Merge Gate

### Prompt

```text
Bu change için merge-readiness değerlendirmesi yap.

Rapor:

- Ready
- Ready with concerns
- Not ready

kategorilerinden biri olsun.

Gerekçeleri evidence ile açıkla.

Özellikle kontrol et:

- tests
- architecture boundary
- unrelated diff
- security/data concerns
- unresolved questions
- review blockers

Merge yapma.
PR merge button veya remote merge action kullanma.

Final merge decision human reviewer'a aittir.
```

### Discussion Point

```text
AI can prepare merge evidence.
AI does not own merge accountability.
```

---

## Module Takeaway

> **Pull Request bir teslim mekanizmasından önce bir review contract'ıdır.**
